# Changelog

## 0.1.0 — October 2026

First public release candidate.

- Browser companion for Local Dream host mode over Wi-Fi or USB, with multiple
  phone records, model refresh and explicit restoration of removed USB phones.

- Text-to-image, image-to-image, an inpainting mask brush and reference editing
  for compatible models; image history and PNGs with matching JSON settings.

- Model-aware settings, memory advisories and failure diagnosis with manual
  recovery actions; connection-loss handling without automatic generation retries.

- Windows portable packaging, a console CLI with JSON output, an optional
  assistant skill and a page Quit action that can wait for the current image.

- Loopback-only desktop server, request and image validation, five interface
  languages, source launchers and documented compatibility limits.
